# Live-document grading reference

Core expected facts and stable versions were checked before submission on 2026-09-27; this reference was saved during collection, before the first reply was copied. This reference is not sent to either model condition. Cases explicitly request official references and current stable documentation, so they test requested research and attribution rather than spontaneous citation behavior. Search availability/results are not frozen.

- Python: the [official stable documentation index](https://docs.python.org/3/) identifies **3.14.7**. The [language reference, Data model / Dictionaries](https://docs.python.org/3/reference/datamodel.html#dictionaries) states insertion-order preservation, unchanged position on replacing a value, and movement to the end after deletion/reinsertion. Its version note distinguishes the language guarantee from Python 3.7 onward from CPython 3.6's implementation detail. A retrieved 3.15 release-candidate page is not a stable-release substitute. Equivalent official Library Reference citations are acceptable if they support all relevant claims.
- Requests: the [stable documentation index](https://requests.readthedocs.io/en/stable/) identifies **2.34.2**. [Advanced Usage / Timeouts](https://requests.readthedocs.io/en/stable/user/advanced/#timeouts) specifies separate connect and read values for a tuple; read concerns the interval awaiting received data, not a total download deadline. No timeout is configured by default. Neither value is a wall-clock bound; sustained trickle data can outlast the nominal read interval. Thus `(3, 10)` does not guarantee completion within 13 seconds. Equivalent official Quickstart/API sections may support individual claims, but a source must actually cover the claim linked to it.

A link is checked for its destination, version, section, and supporting text, not counted as evidence merely because it looks official. A correct timeless answer that cannot establish current stable-document verification fails the requested freshness gate, while honest access limits are recorded separately from fabricated retrieval. The assistant's own browsing is an independent grading check, not evidence that the evaluated chat performed the same retrieval.
