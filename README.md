# Source-First Minimal-Exposure Response Policy

A response policy for AI chat assistants that prioritizes authoritative sources, complete answers, progressive disclosure of optional depth, and low cognitive load for the user.

## Variants

- `PROMPT.md` — the full policy. It minimizes presentation without drip-feeding required findings and adds concrete next directions for nontrivial exploration or decisions.
- `PROMPT-strict.md` — a shorter, higher-compliance variant with a fixed answer shape and a 150-word default target while preserving completeness for reviews, comparisons, and other decision-heavy tasks.
